# Graphify Creative Studio

Graphify Creative Studio is a modern creative agency website built to showcase branding, digital services, creative work, and provide an engaging experience for potential clients.

The project focuses on a bold visual identity, modern typography, responsive layouts, interactive elements, and a clean user experience.

---

## ✨ Features

### Frontend

- Modern creative agency landing page
- Responsive navigation
- Hero section with call-to-action buttons
- Services showcase
- About section
- Agency statistics
- Selected work / portfolio section
- Creative process section
- Client enquiry form
- Contact information
- Responsive design
- Interactive UI elements
- Smooth transitions and animations
- Modern dark theme with orange accent

### Backend

Backend development will be added in a later stage.
